# 番茄超市

番茄小说聚合客户端的 **Windows 桌面版**，图标是一只戴墨镜的大番茄。
单个 exe，免安装，双击即用。

与 Android 版共用同一个 Rust 核心（`fqapi_core`），不是另写一套业务逻辑：小说的签名请求、
设备池轮换、CENC 解密、短剧选流、漫画图片解密全部复用同一条链路。

---

## 快速开始

1. 把 `番茄超市.exe` 复制到任意目录（U 盘、桌面、只读共享都可以）。
2. 双击运行。
3. 首次启动会在 `%LOCALAPPDATA%\fqapp-pc` 建立数据目录，之后所有状态都在那里。

**没有安装步骤、没有服务、没有依赖目录。** 删掉那个数据目录就等于完全卸载。

### 系统要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 21H2 / Windows 11（x64） |
| WebView2 运行时 | 系统自带。Win11 与较新的 Win10 已预装；缺失时安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 即可 |
| 网络 | 需要访问番茄公开接口 |

### 便携模式（可选）

默认数据目录在 `%LOCALAPPDATA%`，这样 exe 本身永远只有一个文件。做成纯 U 盘绿色版：

```powershell
$env:FQPC_HOME = "E:\fqapp-data"
.\番茄超市.exe
```

`FQPC_HOME` 指向的目录会成为唯一的数据落点（含设备池、漫画图片缓存、日志）。

## 功能

保留 Android 版全部分类，栖页（小说精简版）裁掉的短剧、听书、漫剧都在：

| 功能 | 说明 |
| --- | --- |
| 发现 | 番茄书城推荐流与排行榜，封面、作者、分类直达 |
| 搜索 | 小说 / 漫画 / 听书 / 短剧四个频道，结果分页与缓存 |
| 详情 | 作品信息、目录分卷展示、前端缓存下载、后端整本打包下载 |
| 小说阅读 | 正文解密渲染、章节跳转、阅读进度 |
| 听书 | 逐句朗读与进度跟随。优先使用上游音频流；拿不到时用系统语音合成朗读脚本 |
| 短剧 / 漫剧 | 选流播放（自动过滤不支持的编码，同画质优先 h264） |
| 漫画 | 图片解密后本地提供，按章翻页 |
| 书架 | 继续阅读 / 最近浏览 / 收藏，本地保存，标题懒加载 |
| 设置 | 主题、正文字号、行距、音量、倍速、自动下一章 |

## 界面

桌面端重新设计，不是手机页面的放大：

- **常驻侧边栏**：发现 / 搜索 / 书架 / 设置，当前页高亮。
- **固定顶栏**：返回、全局搜索、主题切换。
- **沉浸阅读**：阅读、听书、短剧、漫画四页收起全部界面元素，鼠标移到窗口顶部才唤出；正文占满窗口。
- **宽屏网格**：卡片按窗口宽度自动增减列数，而不是把内容塞进固定宽度的窄列。
- **悬停反馈**：卡片抬升、封面微缩放、清晰的键盘焦点环。

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + K` / `Ctrl + F` | 聚焦搜索框 |
| `Ctrl + L` | 打开书架 |
| `Ctrl + ,` | 打开设置 |
| `Ctrl + D` | 切换浅色 / 深色 |
| `Alt + ←` / `Alt + →` | 后退 / 前进 |
| `S` | 沉浸页（阅读 / 听书 / 短剧 / 漫画）打开设置面板 |
| `F11` | 全屏 |
| `Esc` | 退出全屏，或唤回沉浸页的界面元素 |

阅读与漫画页的界面元素默认隐藏，鼠标移到窗口顶部即可唤出。

## 架构

```
番茄超市.exe  (单个文件)
├── desktop/        Tauri v2 外壳：窗口、托盘式单实例、资源内嵌
├── core/           fqapi_core：与 Android 版完全一致的 Rust 核心
├── ui/             Web UI：发现 / 搜索 / 详情 / 阅读 / 听书 / 短剧 / 漫画 / 书架 / 设置
└── runtime/        默认配置与响应过滤器（编译进 exe，首次启动释放）
```

启动流程：

1. 外壳解析数据目录，把内嵌的 Web UI 与默认配置写进去（UI 每次覆盖以保证升级生效，配置文件只在缺失时创建，不会覆盖用户改动）。
2. 启动 Rust 核心，加载配置、设备池与过滤器，监听 loopback 端口。
3. 窗口直接打开 `http://127.0.0.1:<端口>/_session/<一次性能力>`；适配器把它换成 HttpOnly 会话 Cookie 后重定向到 `/`。

浏览器上下文与 API **同源**，因此不需要任何 CORS 例外，页面也永远拿不到会话能力串。
loopback 保留了 Host / Origin 校验与会话校验，端口固定优先（否则 origin 变化会导致浏览器丢弃本地书架与阅读进度）。

### 为什么端口要固定

Web UI 的 origin 是 `http://127.0.0.1:<端口>`。端口一变，浏览器就当作一个全新站点，
localStorage 里的书架、收藏、阅读位置全部作废。因此外壳优先使用 `config.json` 的 `port`（8080），
被占用时顺延 8 个端口，全都占用才退让给系统随机端口——这时会在日志里明确告警。

## 从源码构建

需要 Rust stable（已在 1.99 上验证）、Node 无需、Tauri CLI 无需。

```powershell
cargo build --release -p fqpc
# 产物: target\release\fqpc.exe
```

或者用封装脚本，它会顺便产出校验和：

```powershell
.\tools\build.ps1
# 产物: dist\番茄超市.exe + dist\SHA256SUMS
```

改过 `ui/` 下的文件后必须重新 `cargo build` —— UI 是编译期内嵌进 exe 的，
不是运行时从磁盘读取。

### 校验

```powershell
cargo test --offline -p fqapi_core          # 核心协议与回归测试
.\tools\check-format.ps1                     # rustfmt 覆盖检查
```

## 已知限制

- **仅 Windows x64。** 外壳用了 Tauri v2 + WebView2，跨平台需要另行适配。
- **设备池明文存储。** Android 版用 Keystore 里的密钥加密设备池，PC 版没有接入 DPAPI，
  核心会在日志里提示 `saving device pool unencrypted`。设备身份存放在
  `%LOCALAPPDATA%\fqapp-pc\config\device_pool.json`，属于本机用户数据。
- **核心测试有 6 项需要 Windows 开发者模式。** 它们验证静态文件服务的符号链接越权防护，
  创建符号链接需要 `SeCreateSymbolicLinkPrivilege`；未开启时这些用例会以
  `os error 1314` 失败，其余 177 项全部通过。
- **部分推荐频道上游可能返回空。** 书城、听书、看剧、漫画频道内容稳定；小说与经典频道
  是否可用取决于番茄当前的 `tab_type` 配置，页面会提示「这个频道暂时没有内容」而不是转圈。
- **听书目前走语音合成。** 上游的音频播放接口会返回 `invalid aid`，拿不到音频流；
  听书改为用系统语音合成朗读上游提供的带时间戳脚本，效果与安卓端的系统 TTS 一致，
  但音色取决于系统里安装的中文语音包。
- **仅内容消费，不提供登录与社交写入。** 与 Android 版范围一致：没有追剧、点赞、分享等写操作。
